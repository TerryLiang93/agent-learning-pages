手写'想→做→看'循环

2026-08-25 · 第一个 Agent · 预计 30 分钟

今日要点

昨天我们讲了 Agent 的"想→做→看"循环概念，但还没动手写代码。今天我们就来把这个循环真正写出来——你会看到，一个 Agent 本质上就是一个会自己决定下一步做什么的 while 循环。学完今天的内容，你就能独立写出一个带终止条件的 Agent 循环，这是所有 Agent 应用的地基。

术语卡片

  • while 循环 —— 就是"只要条件还成立，就一直重复做某件事"的代码结构。比如"只要锅里还有饭，就一直盛"，这就是一个 while 循环。
  • 终止条件 —— 让循环停下来的判断标准。没有终止条件的循环会永远跑下去，就像没有刹车的车。Agent 里通常有两个终止条件：任务完成了，或者步数用完了。
  • ReAct 循环 —— 这是"想→做→看"循环的正式名字。ReAct = Reason（推理）+ Act（行动），就是让 AI 先思考、再行动、观察结果、再思考，循环往复直到解决问题。

原理精讲

先回忆一下昨天的核心：Agent 不是一次问答，而是一个循环。就像你早上出门前：

  1. 想：今天天气怎么样？该穿什么？
  2. 做：打开手机查天气
  3. 看：哦，25 度，有雨
  4. 再想：那穿短袖+带伞
  5. 做：拿伞出门

这个过程就是 ReAct 循环。Agent 做事情也一样——它问大模型"下一步该做什么"，大模型说"调用天气工具"，Agent 就去调用，拿到结果后再问大模型"现在你知道了天气，下一步呢"。

关键点：Agent 自己不会停，你必须告诉它什么时候停。

就像你查天气不会查一整天——查到温度了、决定穿什么了，就结束了。代码里也一样，循环每转一圈，都要检查一次："任务完成了吗？" "转了多少圈了？" 如果完成了就停，如果转太多圈（比如 10 圈）还没完成，也要强制停——防止 Agent 陷入死循环，白白浪费钱和时间。

伪代码大概长这样：

while 没完成 and 步数 < 最大步数:
    问大模型："根据目前信息，下一步做什么？"
    如果是"调用工具"：执行工具，把结果记下来
    如果是"给出最终答案"：标记完成，退出循环
    步数 + 1

就这么简单。下面我们来写真的代码。

动手任务

手机任务（5 分钟）：打开手机备忘录，写下"我今天要做的一个 Agent 循环"的场景（比如：查天气决定穿什么、查菜谱决定做什么饭）。用大白话写出它的"想→做→看"循环，以及两个终止条件分别是什么。不用写代码，写清楚流程就行。

电脑任务（10 分钟）：在电脑上创建 agent_loop.py，复制以下代码并运行：

# agent_loop.py — 一个最简单的 Agent 循环
import random

def think(step, info):
    """模拟大模型的'想'：决定下一步做什么"""
    if step == 0:
        return "call_tool"  # 第一步：查天气
    elif step == 1:
        # 假装大模型看到天气后决定给出答案
        return "answer"
    else:
        return "answer"

def execute_tool():
    """模拟工具：返回天气数据"""
    weather = random.choice(["晴, 28度", "雨, 22度", "多云, 25度"])
    return weather

# ===== Agent 主循环 =====
max_steps = 5          # 终止条件 1：最大步数
task_done = False      # 终止条件 2：任务是否完成
step = 0
info = ""

while not task_done and step < max_steps:
    print(f"--- 第 {step+1} 步 ---")
    
    # 1. 想：让模型决定下一步
    action = think(step, info)
    print(f"模型决定：{action}")
    
    # 2. 做：执行动作
    if action == "call_tool":
        info = execute_tool()
        print(f"工具返回：{info}")
    elif action == "answer":
        # 3. 看：根据信息给出最终答案
        print(f"最终答案：今天{info}，建议穿短袖带伞")
        task_done = True   # 任务完成，终止循环
    
    step += 1

if not task_done:
    print("达到最大步数，强制停止")

运行后观察输出。然后做两个修改练习：

  1. 把 max_steps 改成 2，运行看看会发生什么——你会看到"达到最大步数"的提示，这就是强制终止。
  2. 把 think 函数里 step == 1 的条件改成 step == 3，再运行——体会一下如果模型一直不给出答案，循环是怎么被强制停下来的。
