术语卡片

术语大白话解释
自测清单一张"我到底会不会"的检查表。不是考试，是让你自己发现自己哪里没懂。就像修电路板前先拿万用表量一遍，哪条线路不通，先标出来再修。
薄弱点你答不上来、或者解释得磕磕巴巴的知识点。这不可耻，这是宝贝——因为只有知道哪里不会，才能有针对性地补。工程师管这叫"定位故障"。
提示词（Prompt）你给 Agent 下的"指令"。大白话就是：你跟 AI 说的那句话。但工程师的提示词不是随便说，而是结构化地下指令，像写配置一样。
记忆（Memory）Agent 能记住的东西。分两种：短期记忆（这次对话里记住你刚才说了啥）和长期记忆（存在数据库里，下次对话还能想起来）。就像你工作台上的便利贴（短期）和文件柜（长期）。
工具调用（Tool Calling）Agent 自己决定"我需要查个东西/算个数/调个接口"，然后真的去调一个外部函数。就像你写代码时调用库函数，只不过 Agent 是自己判断"该调了"再调。
计划（Planning）Agent 接到大任务时，先拆成小步骤，按顺序执行。就像你修一台设备，不会上来就拧螺丝，而是先看图纸、定步骤、再动手。
反思（Reflection）Agent 执行完一步后，回头检查一下"这一步结果对不对？要不要调整下一步？"就像你焊完一块板子，先拿万用表测一下通断，再焊下一块。

原理精讲

把 15 天的零件装回整机

想象你是一家小饭店的老板（你就是用户），你雇了一个全能服务员（这就是 Agent）。看看这位服务员是怎么工作的：

第一步：接单（提示词）

你告诉他："今天有 3 桌客人，一桌忌辣，一桌赶时间，一桌是熟客爱吃红烧肉。" 这就是你写的提示词——信息越清楚，他干得越好。你要是只说"你看着办"，他大概率办砸。

第二步：记在脑子里（记忆）

他把你说的记下来（短期记忆），又翻出老客户档案（长期记忆），发现"熟客张先生上次说红烧肉太咸了"——这是长期记忆在起作用。没有记忆的 Agent 就像失忆的服务员，每次都得重新认识你。

第三步：查库存（工具调用）

他跑到后厨看了一眼："五花肉还剩半斤，够做一份红烧肉。" 这个"跑后厨看一眼"的动作，就是 Agent 在调用工具。它自己判断"我需要知道库存信息"，然后主动去查。 如果它不查直接写菜单，发现没肉就尴尬了。

第四步：排顺序（计划）

他脑子过了一遍："红烧肉要炖 40 分钟，得先下单；凉菜 5 分钟，最后再上。" 这就是计划——把大任务拆成小步骤，并且排好先后顺序。

第五步：上菜后检查（反思）

菜上齐了，他转一圈看看：张先生的红烧肉咸淡合适吗？赶时间那桌的菜齐了吗？都 OK，他舒口气。如果不 OK，他会调整——这就是反思。

这五步不是串行的，是循环的。 Agent 执行一步、检查一步、调整一步，再走下一步。就像你调电路：接一根线，量一下，不对就改，对了再接下一根。

为什么今天要自测？

因为"听懂了"和"能讲出来"是两回事。你可能看我的讲解觉得"哦，明白了"，但合上笔记让你自己说"Agent 是怎么工作的"，你可能卡壳。这就像你看别人焊电路觉得简单，自己上手就焊歪了。

自测的本质是主动回忆（Active Recall）——这是认知科学里最有效的学习方式。被动看是"输入"，主动答是"输出"，只有输出才能暴露你的知识漏洞。
