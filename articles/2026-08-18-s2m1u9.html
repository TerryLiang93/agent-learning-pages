今日要点

工程师老铁，今天咱们干一件特别有仪式感的事：让你的电脑第一次开口跟 AI 说话。

你之前可能用过 ChatGPT 网页版，那是别人做好的界面。今天你要做的是——自己写几行代码，直接跟大模型对话。这就像你从"用别人家的水管接水"变成"自己拧开阀门接水"。一旦通了，后面所有自动化、智能化的活儿，都是从这个管道里流出来的。

今天要装一个叫 Python 的软件（相当于给你的电脑装一个"翻译官"），然后拿一把叫 API Key 的钥匙（相当于进门的密码卡），最后发一条消息给 AI 的服务器，让它回你一句话。

全程大概 30 分钟，装软件可能占一半时间。别怕，跟着走就行。

术语卡片

  • API —— 应用程序接口。大白话：一个"约定的窗口"。你往窗口递一张纸条（请求），里面的人给你递回一张纸条（响应）。你不需要知道里面的人怎么工作的，只要知道纸条格式就行。
  • API Key —— 一把专属钥匙。证明"你是你"的凭证，服务器看到这把钥匙就知道你有权限调用，然后按次/按量计费。钥匙丢了别人就能盗用你的额度，所以要藏好。
  • SDK —— 软件开发工具包。大白话：别人帮你打包好的一箱工具。你不需要自己拿螺丝刀拧螺丝（写底层 HTTP 代码），直接用现成的扳手（SDK 里的函数）就行。
  • HTTP —— 一种传纸条的规矩。规定了纸条怎么写（请求格式）、怎么递（方法）、对方怎么回（状态码）。就像快递有面单规范，HTTP 就是网络世界的快递面单规范。

原理精讲

1. 你电脑怎么跟 AI 服务器说话？

想象你在食堂打饭：

  • 你走到窗口（API 地址，比如 https://api.deepseek.com/v1/chat/completions）
  • 你把饭卡递过去（API Key，证明你有钱吃饭）
  • 你说"师傅，来份红烧肉"（请求内容：告诉模型你要什么）
  • 师傅递给你一盘菜（响应内容：模型生成的话）

整个过程是一问一答。你发一次请求，它回一次响应，不会像微信那样持续连接。这就是 HTTP 协议的工作方式：无状态——每次请求都是全新的，服务器不记得你上次说了什么。

2. 为什么要用 Python？

因为 Python 是"胶水语言"，写起来像大白话，而且 AI 圈子的工具几乎都支持 Python。你不用学 C++ 那种底层细节，只要会"拿东西、放东西"就行。

3. 环境变量是什么？

你不想把钥匙写在代码里（因为代码可能会分享给别人），所以把钥匙放在电脑的一个"保险柜"里，代码运行时去保险柜里取。这个保险柜就叫环境变量，是操作系统级别的"全局变量"，任何程序都能读，但只有你自己能设置。

4. 请求和响应的结构长什么样？

发请求时，你要给服务器一个 JSON 格式的"纸条"（JSON 就是一种结构化的文本格式，像填表）：

{
  "model": "deepseek-chat",
  "messages": [
    {"role": "user", "content": "你好，介绍一下你自己"}
  ]
}

服务器回你：

{
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "你好！我是 DeepSeek，一个 AI 助手……"
      }
    }
  ]
}

注意看：请求里你告诉它用哪个模型、说什么话；响应里它把回答放在 choices[0].message.content 这个位置。这就是"解析响应"的意思——从一堆 JSON 里把你要的那句话抠出来。

5. 为什么不用 SDK 也行？

SDK 就是帮你把"发请求-收响应"这个过程封装好。你直接调一个函数，传参数进去，它就把结果给你。不用 SDK 的话，你得手动拼 HTTP 请求头、处理状态码、解析 JSON——麻烦但能学得更深。今天我们用 SDK，省时间。

动手任务

任务 1（手机即可完成）：注册 API 服务商，拿钥匙

  1. 打开你手机浏览器，去 DeepSeek 开放平台（platform.deepseek.com），注册账号。
  2. 进入"API Keys"页面，点"创建 API Key"，复制那串以 sk- 开头的字符串。
  3. 注意：这串钥匙只显示一次！先粘贴到手机备忘录里存着。
如果 DeepSeek 注册有问题，可以用硅基流动（siliconflow.cn），有免费额度，流程类似。

任务 2（电脑任务）：安装 Python

  1. 打开电脑浏览器，去 python.org/downloads，下载 Windows 安装包。
  2. 双击安装，勾选最下面的 "Add Python to PATH"（这步必须勾，不然命令行找不到 Python）。
  3. 点 Install Now，等它装完。
  4. 按 Win + R，输入 cmd 回车，在黑色窗口里输入：
    5.    python --version

如果显示 Python 3.x.x 就成功了。

任务 3（电脑任务）：设置环境变量

  1. 在刚才的黑色窗口里输入（把 你的钥匙 换成你复制的真实 Key）：
    2.    setx DEEPSEEK_API_KEY "你的钥匙"
  2. 关掉窗口，重新打开一个 cmd，输入：
    3.    echo %DEEPSEEK_API_KEY%

如果显示你刚才设置的钥匙，就成功了。

任务 4（电脑任务）：写代码，跑通第一次调用

  1. 安装 SDK。在 cmd 里输入：
    2.    pip install openai

（DeepSeek 兼容 OpenAI 的 SDK，所以装这个就行）

  1. 在桌面上新建一个文件，命名为 first_call.py，用记事本打开，粘贴以下代码：
from openai import OpenAI
import os

# 从环境变量里读钥匙
client = OpenAI(
    api_key=os.environ.get("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com"
)

# 发请求
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "你好，请用一句话介绍你自己"}
    ]
)

# 解析响应
print(response.choices[0].message.content)
  1. 保存文件，然后在 cmd 里输入：
    2.    cd Desktop
   python first_call.py
  1. 看到模型回复的话，恭喜你——你已经完成第一次 API 调用了！

如果报错怎么办？

  • ModuleNotFoundError: No module named 'openai' —— SDK 没装上，重新跑 pip install openai
  • AuthenticationError —— 钥匙不对，检查环境变量是否设置正确
  • ConnectionError —— 网络问题，检查能否访问外网
