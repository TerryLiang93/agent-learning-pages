昨天我们手写了一个 Agent，今天要换个更聪明的做法：用现成框架来搭。框架【术语】就是别人写好的半成品工具箱，你只需要告诉它"我要什么"，不用自己从零造轮子。就像你买宜家家具而不是自己砍树做家具——省时间、少出错。今天学完，你能说出一个主流框架的核心概念，并用它搭出一个带工具的 Agent。

术语卡片

  • Agent 框架 —— 别人写好的、专门用来搭 AI Agent 的代码工具箱。它把"怎么调用大模型""怎么让 Agent 调用工具""怎么管理多轮对话"这些重复劳动都封装好了，你只需要填自己的业务逻辑。
  • Agents SDK —— SDK 是"软件开发工具包"的缩写【术语】，就是一包现成的代码库。OpenAI Agents SDK 就是 OpenAI 官方出的 Agent 框架，用几行代码就能创建一个 Agent，还能给它配工具。
  • 配置式开发 —— 不写一堆逻辑代码，而是通过"填配置"来定义程序行为。就像你设置路由器：不用写代码，只在网页表单里填 WiFi 名字和密码，路由器就按你的配置工作。

原理精讲

为什么要用框架？

想象你要做一顿饭。昨天手写 Agent 就像从种菜开始——你要自己处理大模型 API 调用、自己写工具调用的循环、自己管理对话历史。用框架就像去超市买半成品菜——主料配料都配好了，你只需要下锅炒。

框架帮你解决的重复劳动包括：

  1. 循环控制：Agent 的核心循环是"思考→调用工具→得到结果→再思考"。手写时你要自己写 while 循环，框架里这是内置的。
  2. 工具注册：手写时你要自己解析模型返回的"我想调用某某工具"的指令，然后手动分发。框架里你只需要把函数"注册"进去。
  3. 对话管理：多轮对话时历史消息怎么存、怎么传给模型，框架都帮你处理了。

OpenAI Agents SDK 的核心概念（三个就够）

用生活类比：你要开一家奶茶店（搭一个 Agent）。

  • Agent：就是"店员"。你告诉它"你是奶茶店店员，要热情接待顾客"，它就知道自己该干嘛。对应代码里你创建一个 Agent，给它系统提示词。
  • Tool：就是"店员能用的设备"。比如收银机、封口机。你告诉店员"收银机怎么用"，它需要收钱时就会去用。对应代码里你定义一个普通函数，然后注册给 Agent。
  • Runner：就是"店长"。他不直接接待顾客，但负责协调整个流程——顾客来了，他叫店员去接待；店员要用收银机，他监督操作。对应代码里你调用 Runner 来执行 Agent。

电脑任务（10 分钟）：用 OpenAI Agents SDK 搭一个带工具的 Agent

前置条件：已安装 Python 3.9+，已有 OpenAI API Key。

步骤：

  1. 安装 SDK：
    2.    pip install openai-agents
  1. 创建文件 my_agent.py，写入以下代码：
   from agents import Agent, Runner
   import asyncio

   # 定义一个工具：计算器
   def calculate(expression: str) -> str:
       """计算数学表达式，比如 '1+2' 或 '3*4'"""
       return str(eval(expression))

   # 创建一个 Agent，注册工具
   agent = Agent(
       name="计算助手",
       instructions="你是一个计算助手，用户给你数学表达式，你用计算器工具算出结果。",
       tools=[calculate]  # 把工具注册给 Agent
   )

   # 用 Runner 执行
   async def main():
       result = await Runner.run(agent, "帮我算一下 23*17 等于多少？")
       print(result.final_output)

   asyncio.run(main())
  1. 运行：
    2.    export OPENAI_API_KEY="你的key"
   python my_agent.py
  1. 对比昨天手写的代码，观察：你不需要自己写"解析模型输出→决定是否调工具→把结果传回模型"的循环，框架全帮你做了。

验证标准：程序能输出 391 这个结果，并且你能说出代码里 Agent、Tool、Runner 分别对应哪部分。
