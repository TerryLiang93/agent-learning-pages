给 Agent 装'手'：实现第一次工具调用

2026-08-23 · 第一个 Agent · 预计 30 分钟

今日要点

今天给 Agent 装"手"——让它不只是聊天，而是能真正帮你干活。核心是学会一种三方协作的模式：你写代码、模型做决定、程序去执行。就像你请了个助理，助理不会自己泡咖啡，但他会告诉你怎么泡，你去执行，再把结果告诉他。今天跑通这个闭环，你的 Agent 就从"嘴炮"变成"能干活"了。

术语卡片

工具定义 —— 给模型看的"说明书"，告诉它"我有这个功能，你要用的时候按这个格式来喊我"。相当于餐厅菜单：上面写了菜名（函数名）、简介（描述）、原料（参数），顾客（模型）照着点菜就行。

JSON —— 一种通用的数据交换格式，长得像嵌套的字典。你可以把它理解成"填好的表格"：有键（字段名）有值（内容），机器和人都能看懂。比如 {"city": "北京", "days": 3} 就是一条 JSON。

参数解析 —— 把模型返回的"点菜单"拆开，取出里面的具体数值，传给对应的函数。就像服务员把顾客写的"牛肉面，少辣"翻译成后厨能执行的指令：面条=牛肉面，辣度=少。

原理精讲

先想一个生活场景：你让同事帮你查一下明天的天气。你们俩的对话应该是什么样的？

  1. 你告诉同事："我有查天气的 App，你要查的时候告诉我城市名就行"（声明工具）
  2. 同事说："我想查北京的天气"（模型返回调用请求）
  3. 你打开 App 输入"北京"，看到结果后告诉同事："北京明天 25 度，晴"（程序执行并回传结果）

工具调用的原理就是这个，只是把"同事"换成了"大模型"，把"你"换成了"你写的代码"。

具体到代码层面，分三步：

第一步：给模型看"菜单"。你定义一个 JSON 结构，描述你的函数叫什么、干什么用、需要什么参数。这个结构叫"工具定义"【术语】。模型本身不会执行任何代码，它只是"读菜单"。

第二步：模型回传"点单"。当你问模型"北京天气怎么样"时，模型看到菜单上有"查天气"这个工具，就会返回一段特殊格式的 JSON【术语】：{"name": "query_weather", "arguments": {"city": "北京"}}。注意，模型不会真的去查，它只是告诉你"我想用这个工具，参数是这个"。

第三步：你自己执行。你的代码收到这段 JSON 后，做参数解析【术语】——把 city 的值取出来，调用你写的 query_weather("北京") 函数，拿到结果，再拼成一句自然语言回传给模型。模型收到结果后，就能继续回答用户的问题了。

关键点：模型是"大脑"，你的代码是"手"。模型负责判断该用什么工具、给什么参数，你的代码负责真正干活。两者通过 JSON 这个"纸条"交流。

动手任务

手机任务（5 分钟）：打开任意一个能调用工具的 AI 应用（如 ChatGPT、Claude 的 App），问它"现在几点了"或"帮我算 123×456"。观察它是否先显示"正在调用工具"，再给出答案。体会"模型提议→程序执行→结果回传"的过程。

电脑任务（10 分钟）：用 Python 实现一个"当前时间"工具调用。

# 1. 安装依赖：pip install openai
from openai import OpenAI
import json
from datetime import datetime

client = OpenAI()  # 确保已设置 OPENAI_API_KEY 环境变量

# 第一步：声明工具（给模型看的"菜单"）
tools = [{
    "type": "function",
    "function": {
        "name": "get_current_time",
        "description": "获取当前日期和时间",
        "parameters": {
            "type": "object",
            "properties": {},  # 这个工具不需要参数
            "required": []
        }
    }
}]

# 第二步：发消息，模型会"提议"调用工具
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "现在几点了？"}],
    tools=tools
)

msg = response.choices[0].message
print("模型返回的原始内容:", msg.tool_calls[0].function)

# 第三步：解析参数并执行（参数解析）
tool_call = msg.tool_calls[0]
args = json.loads(tool_call.function.arguments)  # 解析 JSON
result = get_current_time()  # 执行真正的函数

# 第四步：把结果回传给模型
response2 = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "user", "content": "现在几点了？"},
        msg,  # 模型的工具调用请求
        {
            "role": "tool",
            "tool_call_id": tool_call.id,
            "content": result  # 工具执行结果
        }
    ],
    tools=tools
)

print("最终回答:", response2.choices[0].message.content)

跑通后，你会看到模型先返回一段 JSON 说要调用工具，然后你的代码执行函数，最后模型基于结果给出回答。
