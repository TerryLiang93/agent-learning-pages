给 Agent 加记忆：向量数据库入门

2026-08-28 · 让 Agent 更聪明 · 预计 30 分钟

今日要点

今天学的是怎么给 Agent 加“记忆”。核心思路是：把文字变成一串数字（向量），让意思相近的文字在数字空间里“离得近”，然后 Agent 就能快速找到“跟当前问题最相关”的历史内容。你会亲手跑通一个带记忆的示例，理解“嵌入”和“相似度检索”这两个词到底在说什么。

术语卡片

  • 嵌入（Embedding） —— 把一段文字（比如一句话）转换成一串固定长度的数字（比如 384 个数字）。这串数字能“概括”这句话的意思，就像给一句话拍了一张“语义照片”。
  • 向量（Vector） —— 就是那串数字本身。可以想象成高维空间里的一个点。两个向量的“距离”越近，表示两句话的意思越接近。
  • 相似度检索（Similarity Search） —— 给定一个查询向量，从一堆向量里找出“距离最近”的那几个。就像你在手机通讯录里搜“老王”，系统按拼音/笔画相似度把最接近的联系人列出来。

原理精讲

为什么文字能变成数字？

你不需要理解神经网络内部怎么算的，只需要知道：有一个模型（比如 all-MiniLM-L6-v2），你给它输入“今天天气真不错”，它会输出一个 384 维的向量。你再输入“阳光明媚适合出门”，输出的向量会和前一个非常接近（距离小）。但你输入“我肚子饿了”，输出的向量就离得远。

这是怎么做到的？ 训练这个模型时，喂了大量“意思相近的句子对”，模型学会了把同义句映射到相近的位置。这就像你给每个朋友拍了一张“脸部特征向量”（眼睛大小、脸型、肤色），长相相似的人特征向量就接近。

向量数据库干什么用？

假设你存了 10 万条笔记。用户问“上次讨论的电源方案是什么”，你不可能把 10 万条笔记全部发给大模型（太贵太慢）。正确做法是：

  1. 把用户的问题也转成向量。
  2. 在向量数据库里快速找到“距离最近”的 3~5 条笔记。
  3. 只把这 3~5 条笔记发给大模型，让它基于这些内容回答。

向量数据库就是专门干这个的——它用特殊索引结构（如 HNSW），能在几毫秒内从上百万个向量里找到最近的几个。普通数据库按关键词匹配做不到“语义相似”，比如你搜“电源方案”，它找不到“供电设计”这条笔记，但向量检索可以。

动手任务

手机任务（5 分钟）：打开浏览器访问 https://huggingface.co/spaces/mteb/leaderboard （文本嵌入榜单）。随便点一个模型，看它的“维度”和“平均分数”。感受一下：不同模型输出的向量长度不一样（384、768、1536 等），分数越高表示“语义理解能力越强”。不用看懂细节，只需要知道“嵌入模型有很多种，效果有差异”。

电脑任务（10 分钟）：跑通一个带记忆的示例。

步骤 1：安装依赖（在终端执行）：

pip install chromadb sentence-transformers

步骤 2：创建 memory_demo.py，粘贴以下代码：

from sentence_transformers import SentenceTransformer
import chromadb

# 1. 加载嵌入模型（把文字变成向量）
model = SentenceTransformer('all-MiniLM-L6-v2')

# 2. 创建向量数据库（本地文件存储）
client = chromadb.PersistentClient(path="./my_memory")
collection = client.get_or_create_collection("notes")

# 3. 存入几条“笔记”（带 ID）
notes = [
    "用户喜欢简洁的回答，不要长篇大论",
    "项目使用 RK3588 平台，双摄像头方案",
    "用户是硬件工程师，软件基础偏弱",
]
collection.add(
    documents=notes,
    ids=["note1", "note2", "note3"]
)

# 4. 模拟用户提问：语义检索
query = "做嵌入式开发的人有什么特点？"
results = collection.query(query_texts=[query], n_results=2)

print("问题：", query)
print("找到的相关笔记：")
for doc, dist in zip(results['documents'][0], results['distances'][0]):
    print(f"  - {doc} (距离: {dist:.4f})")

步骤 3：运行 python memory_demo.py，观察输出。你会看到“用户是硬件工程师，软件基础偏弱”被检索出来（距离最小），尽管问题里没有“硬件”这个词——这就是语义检索。

步骤 4（进阶）：把 n_results 改成 1，再运行一次，看看只返回最相关的一条是什么。

AI 工具箱

今日推荐：用 ChromaDB 给 Agent 加长期记忆

【这是什么】 ChromaDB 是一个轻量级向量数据库，Python 直接调用，无需部署服务器。配合 sentence-transformers 嵌入模型，十几行代码就能给 Agent 加上“记忆”。

【有什么用】 让 Agent 能记住项目背景、用户偏好、历史决策。下次对话时先查记忆库，再回答，而不是每次都“从零开始”。

【怎么用】

  1. 装库：pip install chromadb sentence-transformers
  2. 创建集合（类似数据库表）：collection = client.get_or_create_collection("project_memory")
  3. 写入记忆：collection.add(documents=["..."], ids=["id1"])
  4. 查询：collection.query(query_texts=["当前问题"], n_results=3)

【实用例子】 你正在做一个 RK3588 双摄像头项目，每天结束前把当天的关键决策存进 ChromaDB（比如“IMX219 摄像头 I2C 地址是 0x10”）。第二天问 Agent“摄像头地址是多少”，它能直接从记忆库检索出来，不用你再翻聊天记录。
