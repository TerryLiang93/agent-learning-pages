自己写一个'对话循环'

2026-08-21 · 环境准备 · 预计 30 分钟

今日要点

昨天我们讲了消息列表，今天要把它真正用起来。你会写一个命令行小程序，让 AI 记住你说过的话，实现连续对话。核心就一句话：多轮对话不是 AI 记性好，而是我们把聊天记录每次一起发给它。学完这个，你就明白为什么对话越长越费钱、越容易"犯糊涂"。

术语卡片

  • 消息列表 —— 就是一个数组/列表，里面按顺序存着每一条消息，每条消息带"谁说的"（角色）和"说了啥"（内容）。就像你和朋友的微信聊天记录，一条一条排着。
  • 多轮对话 —— 你和 AI 你一句我一句连续聊下去，AI 能"记得"你前面说过什么。本质是每次提问时，把之前所有的对话记录都打包发给 AI。
  • 历史消息 —— 就是前面几轮你说过的话和 AI 回答过的话的集合。AI 没有记忆，历史消息就是它的"临时记忆"，你不发它就想不起来。

原理精讲

先想一个问题：AI 有记忆吗？

没有。AI 就像一个只有 3 秒记忆的人。你问它"我的名字是张三"，它会回答"好的"。你再问"我叫什么？"——它完全不记得。因为它每次收到的问题，都只是你当前发的那一句话。

那怎么让它"记住"？

很简单：每次你问问题的时候，把前面所有的对话也一起发过去。

打个比方：你和一个失忆的朋友聊天。为了让他记住你叫张三，你每次开口前，都先念一遍之前的对话记录："我说过我叫张三，你也说记住了，现在我问你：我叫什么？"——他当然能答对。

这就是多轮对话的全部秘密。

程序上，我们维护一个消息列表，像这样：

[
  {"role": "system", "content": "你是一个乐于助人的助手"},
  {"role": "user", "content": "我叫张三"},
  {"role": "assistant", "content": "你好张三！"},
  {"role": "user", "content": "我叫什么？"}
]

每次调用 AI 接口时，把整个列表发过去。AI 看完整个列表，就知道你叫张三了。然后它回答完，我们把它的回答也追加到列表里，等下一轮再发。

为什么对话越长越贵、越容易糊涂？

因为每次都要把全部历史发过去。假设你聊了 100 轮，每轮 100 个字，那第 101 轮你要发送大约 1 万字的文本。AI 按字数（token）收费，所以越聊越贵。而且 AI 处理超长文本时，注意力会分散，容易"忘了"前面说的细节——就像你看一篇超长的文章，看到后面就忘了开头。

动手任务

手机任务（5 分钟）

打开任意一个 AI 聊天 App（如 ChatGPT、豆包等），做一个小实验：

  1. 第一句说："请记住，我的暗号是'蓝鲸'。"
  2. 接着随便聊两句别的。
  3. 然后问："我的暗号是什么？"
  4. 再开一个新对话，直接问同样的问题。

观察：同一个 AI，为什么第一个对话能答对，新对话答不上来？想明白你就掌握了多轮对话的本质。

电脑任务（10 分钟）

写一个最简单的命令行聊天程序。需要你有 Python 和一个 API Key（OpenAI 或任意兼容接口的厂商）。

步骤：

  1. 安装依赖：
    2. pip install openai
  1. 新建文件 chat.py，粘贴以下代码：
from openai import OpenAI

client = OpenAI(api_key="你的API_KEY", base_url="你的接口地址")

# 消息列表：程序的核心记忆
messages = [
    {"role": "system", "content": "你是一个友好的助手。"}
]

print("开始聊天吧！输入 exit 退出。")

while True:
    user_input = input("你：")
    if user_input == "exit":
        break
    
    # 1. 把用户的话追加到消息列表
    messages.append({"role": "user", "content": user_input})
    
    # 2. 把整个消息列表发给 AI
    response = client.chat.completions.create(
        model="你的模型名",
        messages=messages
    )
    
    # 3. 拿到 AI 回复
    reply = response.choices[0].message.content
    
    # 4. 把 AI 的回复也追加到消息列表
    messages.append({"role": "assistant", "content": reply})
    
    print(f"AI：{reply}")
  1. 运行：python chat.py
  1. 测试：先告诉它"我叫张三"，隔几句再问"我叫什么？"——它能答对。然后观察：聊得越久，每次发送前程序里 messages 越长。

关键代码就 3 行： 追加用户消息 → 发整个列表 → 追加 AI 回复。循环往复，就是多轮对话。
