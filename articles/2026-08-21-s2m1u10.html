自己写一个'对话循环'

2026-08-21 · 环境准备 · 预计 30 分钟

今日要点

今天咱们干一件特别有成就感的事：自己写一个能连续聊天的程序。你可能会想，聊天谁不会？但关键是搞明白——为什么AI能记住你上一句说了啥？其实原理简单得吓人：每次对话，把之前说过的话全部打包再发给AI一次。今天你就亲手实现它，顺便看看"记性太好"会带来什么代价（钱和速度）。

术语卡片

  • 消息列表 —— 就是一个"聊天记录"清单，里面按顺序装着"用户说"和"AI说"的每一句话。AI本身没记性，全靠你每次把这张清单递给它，它才知道你们聊到哪了。
  • 多轮对话 —— 就是"有来有回地聊天"。比如你先问"1+1等于几"，AI答"2"，你再问"那再加1呢"，AI能答"3"。能做到这个，靠的就是把第一轮的话也一起发给AI。
  • 历史消息 —— 就是之前几轮对话的内容。注意，它不是AI自己记住的，而是你（程序）负责保存、负责再次发给AI。AI只是个"一次性"的应答机。

原理精讲

想象一下：你找一位健忘的同事帮忙干活（这位同事就是AI大模型）。他每次只认一张纸条，你递给他什么，他就看什么，干完活纸条就扔了。

  • 第一轮，你递纸条："1+1等于几？" 他答："2"。
  • 第二轮，如果你只递纸条："那再加1呢？" 他会懵——"什么再加1？" 因为他已经把上一张纸条扔了。

解决办法：第二轮的时候，你递给他一张更长的纸条，上面写着：

用户：1+1等于几？
AI：2
用户：那再加1呢？

他一看就明白了："哦，是2+1，等于3！"

这就是多轮对话的全部秘密：你的程序负责把"历史消息列表"（那张越来越长的纸条）和"新问题"拼在一起，一次性发给AI。AI不记事儿，但"纸条"记得。

那"上下文变长后发生了什么"？就像纸条越写越长，两个问题立刻出现：

  1. 成本变高：AI是按"字数"收费的。纸条越来越长，你每次付的钱就越多。聊100轮，每次都带着前99轮的"废话"去付钱。
  2. 效果变差：纸条太长，AI容易"看花眼"，找不到重点。就像让你从一篇万字长文里找一句话，反而容易找错。专业说法叫"注意力分散"。

动手任务

手机任务（5分钟）

打开你手机里任何一个能聊天的AI应用（比如豆包、Kimi、ChatGPT）。开始以下对话，观察它的反应：

  1. 问："给我推荐一部科幻电影。"
  2. 追问："这个导演还拍过什么？" （注意：它记得刚才推荐的是哪部）
  3. 再问："刚才推荐的第二部，评分多少？" （如果它推荐了多部，看看它记不记得）

思考：如果它答对了，说明它内部也用了"消息列表"机制。

电脑任务（10分钟）—— 写一个命令行聊天程序

前提：你电脑上需要有 python 和 openai 库（pip install openai）。如果没有API Key，可以用模拟数据跑通逻辑。

步骤：

  1. 新建文件 chat.py，复制以下代码（注意：如果你没有真实API Key，看第4步的"模拟模式"）：
# chat.py - 多轮对话演示程序
import openai

# 你的API密钥（在platform.openai.com申请）
client = openai.OpenAI(api_key="你的KEY")

# 核心数据结构：消息列表。一开始是空的。
messages = []

print("开始聊天！输入 'quit' 退出。")

while True:
    user_input = input("你: ")
    if user_input == "quit":
        break

    # 1. 把用户的新消息，追加到历史列表里
    messages.append({"role": "user", "content": user_input})

    # 2. 把整个消息列表（历史+新问题）一起发给AI
    response = client.chat.completions.create(
        model="gpt-4o-mini",  # 便宜够用
        messages=messages     # 这就是"多轮对话"的关键！
    )

    # 3. 拿到AI的回复
    ai_reply = response.choices[0].message.content
    print(f"AI: {ai_reply}")

    # 4. 把AI的回复也存进历史列表，供下一轮使用
    messages.append({"role": "assistant", "content": ai_reply})

    # 5. 观察消息列表有多长（这就是"成本"）
    total_chars = sum(len(m["content"]) for m in messages)
    print(f"[提示] 当前历史消息总字数: {total_chars}")
  1. 运行：在终端执行 python chat.py，然后连续聊几句，比如"我喜欢科幻片"、"推荐一部"、"为什么推荐这部？"。
  1. 观察：注意每次打印的"历史消息总字数"在增加。这就是为什么聊得越久越花钱。
  1. 没有API Key怎么办？ 把第2步替换成模拟回复（不需要联网）：
    # 模拟AI回复（把"你"的问题原样返回，假装在回答）
    ai_reply = f"（模拟回复）你刚才说的是：{user_input}"

这样你也能完整跑通"多轮对话"的逻辑结构。
