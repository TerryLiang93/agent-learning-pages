Python 与 API：第一次调用大模型

2026-08-20 · 环境准备 · 预计 30 分钟

今日要点

昨天咱们的课程推了但你没来得及看，没关系，今天咱们重新走一遍，而且我会讲得更细。

今天你要做的事其实就一件：让你的电脑开口跟 AI 对话。就像你第一次用微信发消息一样——输入一句话，点发送，对方回你一句。只不过这次"对方"不是人，是大模型，而"微信"是你自己写的几行 Python 代码。

这件事为什么重要？因为这是你从"看别人玩 AI"到"自己指挥 AI"的分水岭。以后你想让 AI 帮你总结文档、分析日志、生成代码，底层都是今天这个动作——发请求，收响应。

今天的课分四步：装 Python → 拿钥匙（API Key）→ 写代码 → 看到回复。每一步我都会告诉你"做到什么程度算完"，不贪多。

术语卡片

API —— 饭店的"点餐窗口"。你不需要知道后厨怎么炒菜，只要对着窗口喊"来份宫保鸡丁"，厨房就会把菜端出来。大模型的 API 就是这个窗口，你发一句话过去，它把回答送回来。

API Key —— 饭店的"会员卡"。证明你有资格点餐、也方便饭店记账（谁点了多少菜、该扣谁的钱）。没有这张卡，窗口不搭理你。

SDK —— 饭店提供的"套餐菜单"。本来你得自己研究"怎么喊话厨房才听得懂"，SDK 就是官方给你配好的点餐工具，照着菜单勾选就行，不用自己发明语言。简单说，SDK 是别人写好的代码包，你拿来直接用。

HTTP —— 送餐的"外卖骑手"。你的请求和模型的响应，都靠它来回跑。它不关心你点了什么菜，只负责把餐盒从 A 地送到 B 地。在代码里你会看到它，但不用深究。

原理精讲

1. 整个流程长什么样？

想象你去一家叫"大模型"的餐厅：

  1. 你（Python 代码）走到点餐窗口（API 地址）
  2. 出示会员卡（API Key）
  3. 对着窗口喊："帮我写一句欢迎词"（请求内容）
  4. 厨房忙活一会儿（模型推理）
  5. 外卖骑手（HTTP）把菜端回来（响应内容）
  6. 你打开餐盒，看到一句话（模型的回复）

整个过程在你的电脑上只需要几行代码就能完成。难点不在代码本身，而在于第一次把环境配好——就像第一次去一个新餐厅，你得先找到门在哪。

2. 为什么需要 Python？

Python 是"翻译官"。你直接用中文跟电脑说"帮我调 AI"，电脑听不懂。但 Python 这种编程语言，电脑能听懂，而且它有很多现成的"翻译工具"（就是 SDK），让你不用从零开始造轮子。

打个比方：你想去国外餐厅点菜，Python 是随身翻译，SDK 是翻译官手里的菜单模板——你只需要填上"要什么菜"就行，不用自己背整套外语。

3. API Key 为什么不能乱放？

API Key 相当于你银行卡的密码。谁拿到它，谁就能用你的额度去调 AI，产生的费用算你头上。

所以保存原则就一条：不要把 Key 直接写在代码文件里。因为代码文件可能会被分享、上传到 GitHub，一旦泄露就是裸奔。

正确做法是存在环境变量里——这是 Windows 系统自带的一个"小抽屉"，只有你的电脑能打开，代码运行时从抽屉里取钥匙，但钥匙本身不写在代码里。

动手任务

手机任务（5 分钟）

打开手机备忘录，回答以下三个问题，不用给任何人看，自己心里有数就行：

  1. 你电脑上现在有没有装 Python？如果不知道，怎么查？（提示：按 Win + R，输入 cmd 回车，在黑窗口里输入 python --version）
  2. 你有没有任何一个大模型的账号（OpenAI、DeepSeek、通义千问、Kimi 等）？
  3. 你的电脑是 Windows 哪个版本？（Win10 还是 Win11，右键"此电脑"→"属性"就能看到）

这三个问题决定了后面的步骤，先摸清家底。

电脑任务（10 分钟）：安装 Python

如果你已经装过 Python，直接跳到下一步。

步骤 1：下载

打开浏览器，访问 https://www.python.org/downloads/，点黄色大按钮下载最新版。

步骤 2：安装（关键一步）

双击下载好的安装包，第一屏最下面有一个复选框 "Add Python to PATH"，一定要打勾！ 这是新手最容易漏的，不打勾后面命令全不认。

然后点 "Install Now"，等它跑完。

步骤 3：验证

按 Win + R，输入 cmd 回车，在黑色窗口里输入：

python --version

如果显示 Python 3.xx.x 这样的字样，就说明装好了。

电脑任务（10 分钟）：第一次调用

前提：你需要有一个大模型的 API Key。如果你还没有，推荐用 DeepSeek（https://platform.deepseek.com），注册后充值几块钱就能拿到 Key，便宜且国内直连。

步骤 1：安装 SDK

在刚才那个黑色窗口里输入：

pip install openai
注意：DeepSeek 的接口兼容 OpenAI 的 SDK，所以装这个就行。pip 是 Python 自带的"软件安装器"，这行命令的意思是"帮我装一个叫 openai 的工具包"。

步骤 2：设置环境变量

按 Win 键，搜索"环境变量"，打开"编辑系统环境变量"→ 点右下角"环境变量"→ 在"用户变量"区点"新建"：

  • 变量名：DEEPSEEK_API_KEY
  • 变量值：粘贴你的 API Key（sk-开头的一串字符）

点确定。然后关掉黑色窗口重新打开一个（不然新变量不生效）。

步骤 3：写代码

在桌面新建一个文本文件，改名为 first_call.py（注意扩展名从 .txt 改成 .py）。右键用记事本打开，粘贴以下内容：

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "你好，请用一句话介绍你自己"}
    ]
)

print(response.choices[0].message.content)

步骤 4：运行

在黑色窗口里输入：

cd Desktop
python first_call.py

如果看到模型回了一句话，恭喜你——第一次 API 调用成功了！
