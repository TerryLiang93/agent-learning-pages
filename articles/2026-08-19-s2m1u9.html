术语卡片

API —— 就是"一个约定的接口"。好比餐厅的菜单：你不用进厨房，只要照着菜单点菜，厨房就会按规矩把菜做出来给你。API就是那个"菜单"，你按格式发请求，服务器按格式回结果。

API Key —— 就是"你的身份凭证"。好比小区门禁卡，刷卡才能进。API Key是一串字符串，贴在请求里，服务器一看就知道"哦，这是合法用户，放行"。

SDK —— 就是"别人帮你写好的工具包"。好比买家具附带的六角扳手，你不用自己找工具，直接用这个扳手就能组装。SDK就是官方提供的Python工具包，帮你省去手写底层请求的麻烦。

HTTP —— 就是"互联网上沟通的规矩"。好比写信的格式：要有收件人地址、要有正文、要有落款。HTTP规定了请求和响应的格式，所有网络通信都按这个规矩来。

原理精讲

1. 整个流程长什么样

先给你一张全景图，心里有个数：

你的电脑 (Python)  --HTTP请求-->  大模型服务器 (OpenAI/其他)  
你的电脑 (Python)  <--HTTP响应--  大模型服务器

就这么简单。你的电脑发一条消息过去，服务器算一会儿，把结果发回来。

但这里有个关键问题：服务器怎么知道你是谁？ 这就要靠API Key了。

2. API Key 到底怎么用

想象你去银行办业务。柜员问："您好，请出示身份证。" 你递过去，柜员核对完，开始办业务。

API Key就是你的"身份证"。每次发请求，你都要把API Key带上，服务器核对无误后才给你干活。

安全保存是重点中的重点。因为API Key是花钱的——每次调用都按量计费。如果泄露了，别人就能用你的额度，月底账单吓死你。

保存方法：不要硬编码在代码里，而是放在环境变量里。

环境变量【术语】就是"操作系统里存的全局变量"，任何程序都能读。好比你家大门后面挂了一块白板，上面写着WiFi密码，家里任何人要用都能看，但外人进不来。

具体操作（Windows）：

  • 按 Win 键，输入"环境变量"，回车
  • 点"环境变量"按钮
  • 在"用户变量"里点"新建"
  • 变量名填 OPENAI_API_KEY，变量值填你的Key
  • 确定，关掉所有窗口

这样你的Python代码就能通过 os.getenv("OPENAI_API_KEY") 读到它，而代码里不出现明文Key。

3. HTTP请求到底是什么

咱们刚才说了HTTP是"规矩"。具体到今天的场景，你发出去的请求长这样（简化版）：

POST https://api.openai.com/v1/chat/completions
Headers: 
  Authorization: Bearer sk-xxxxx
  Content-Type: application/json
Body:
  {
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "你好"}]
  }

翻译成人话：

  • POST：我要提交东西（不是拿东西，GET才是拿）
  • URL：我要送到哪个地址（大模型服务器的门牌号）
  • Headers：信封上的附加信息（你是谁、你发的是什么格式）
  • Body：信的正文（你要问的话）

服务器返回的响应长这样（简化版）：

{
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "你好！有什么可以帮你的吗？"
      }
    }
  ]
}

choices 就是一个列表，里面装着模型的回复。content 字段就是那句人话。

4. 用SDK还是直接发HTTP？

两种方式都能实现。但咱们用SDK，因为省事。SDK相当于把上面那些HTTP细节都封装好了，你只需要写：

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "你好"}]
)
print(response.choices[0].message.content)

就这么简单。SDK内部帮你自动处理了HTTP请求、Headers、JSON解析这些脏活累活。

把答案写下来，这是你今天的起点。

电脑任务（10分钟）

前提：假设你已经有OpenAI账号（或者兼容OpenAI接口的平台，比如智谱、DeepSeek等）。如果没有，先去平台注册并创建一个API Key。

第1步：安装Python

  1. 打开浏览器，访问 https://www.python.org/downloads/
  2. 点击黄色的"Download Python 3.12.x"按钮
  3. 下载完后双击安装包
  4. 重要：勾选"Add Python to PATH"（这步不勾后面会哭）
  5. 点"Install Now"，等它装完

验证：打开命令行（Win + R，输入cmd回车），输入：

python --version

看到 Python 3.12.x 就说明装好了。

第2步：安装OpenAI SDK

命令行里输入：

pip install openai

看到 Successfully installed openai-xxx 就说明装好了。

第3步：设置环境变量

按前面的方法，把API Key存到环境变量 OPENAI_API_KEY 里。

第4步：写代码

在桌面新建一个文件夹 ai_learning，在里面新建文件 first_call.py，用记事本打开，粘贴以下内容：

import os
from openai import OpenAI

# 从环境变量读取API Key
client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY")
)

# 发第一次请求
response = client.chat.completions.create(
    model="gpt-4o-mini",  # 如果你用的是其他平台，改成对应的模型名
    messages=[
        {"role": "user", "content": "你好，请用一句话介绍你自己"}
    ]
)

# 打印模型的回复
print("模型的回复：", response.choices[0].message.content)

第5步：运行

命令行里进入那个文件夹：

cd Desktop\ai_learning
python first_call.py

看到类似输出：

模型的回复： 你好！我是AI助手，可以帮你解答问题、提供建议、处理信息……

恭喜，你跑通了！

如果报错，最常见的两个：

  • ModuleNotFoundError: No module named 'openai' → 说明SDK没装好，重新执行第2步
  • AuthenticationError → 说明API Key没配对，检查环境变量是否设置正确
