用现成框架搭 Agent

2026-08-25 · 第一个 Agent · 预计 30 分钟

今日要点

今天我们要告别"手写轮子"——之前你从零搭 Agent 的方式，就像自己种小麦做面包。而框架（Framework）就是"面包机"：把常用功能都封装好了，你只需要放好原料、按几个按钮。今天学一个主流框架的核心概念，然后用它配出一个带工具的 Agent，对比一下和手写版的区别。

术语卡片

  • Agent 框架 —— 别人写好的"半成品厨房"，锅碗瓢灶都备齐了，你只管按菜谱做菜，不用自己打铁铸锅。
  • Agents SDK —— SDK 就是"软件工具箱"的缩写。Agents SDK 是 OpenAI 官方提供的 Agent 工具箱，里面已经装好了"让 AI 调用工具、记住对话、按流程办事"这些常用零件。
  • 配置式开发 —— 不写一堆逻辑代码，而是用"填表"的方式告诉程序"你要什么"，程序自动帮你拼装好。就像点外卖：你勾选菜品和口味，后厨自动出餐。

原理精讲

为什么用框架？

打个比方：你之前手写 Agent，相当于自己用砖头砌墙。砌一面墙没问题，但你要砌 100 面墙（做 100 个 Agent），每面墙都要重新搬砖、和水泥——太累了。框架就是"预制板"：墙板是工厂做好的，你只管把墙板拼起来，省下大量重复劳动，把精力放在"这面墙放哪、开几个窗户"（也就是你的业务逻辑）上。

核心概念：Agent、工具、循环

以 OpenAI Agents SDK 为例，核心就三个词：

  1. Agent（智能体） —— 一个"有脑子的工人"。你给它一个名字和一句"岗位说明"（system prompt），它就知道自己是干嘛的。
  2. Tool（工具） —— 工人的"双手"。比如"查天气"是一个工具，"算加法"是另一个工具。Agent 脑子不够用时，会调用工具来干活。
  3. 循环（Loop） —— 工人干活的流程：接到任务 → 想想需要啥工具 → 调用工具 → 拿到结果 → 再想想 → 再调用……直到任务完成。

配置式开发长什么样？

手写版你要写：if 用户说查天气 then 调用天气API 这种判断逻辑。配置版你只需要写：

agent = Agent(
    name="天气助手",
    instructions="你是一个天气查询助手，用户问天气时用 get_weather 工具",
    tools=[get_weather]
)

框架自动帮你处理"什么时候调用工具、调用后怎么把结果给 AI"这些脏活累活。

动手任务

第一步（手机可做，2 分钟）：打开 OpenAI 官网的 Agents SDK 文档页（搜索关键词：OpenAI Agents SDK），只看首页的"核心概念"部分，找到 Agent、Tool、Loop 这三个词，截图保存。

第二步（电脑任务，8 分钟）：在电脑上装好环境后，跑通第一个框架版 Agent：

# 1. 安装（终端执行）
pip install openai-agents

# 2. 新建文件 demo.py，粘贴以下代码
from agents import Agent, Runner

# 定义一个带工具的 Agent —— 工具就是一个普通函数
def get_weather(city: str) -> str:
    """查天气的假工具，实际项目里这里会调天气 API"""
    return f"{city} 今天晴天，25度"

agent = Agent(
    name="天气助手",
    instructions="用户问天气时，用 get_weather 工具回答",
    tools=[get_weather],
)

# 3. 运行（终端执行）
result = Runner.run_sync(agent, "北京天气怎么样？")
print(result.final_output)

跑通了你就发现：手写版你要自己写"判断用户意图→调用函数→拼回答"的循环，框架版只写了三行配置，循环是框架自动完成的。

AI 工具箱

主题：让 Agent 自己写"使用说明书"——AGENTS.md 的崛起

【这是什么】最近 GitHub 上最大的 100 个仓库都在往项目里加一个叫 AGENTS.md 的文件。它不是给人看的，是给 AI 编程助手（如 Claude Code）看的"项目使用说明书"。

【有什么用】AI 代理进到你的代码仓库时，先读这个文件，就知道"这个项目怎么跑、代码风格是什么、有哪些坑别踩"。就像新同事入职第一天，先看部门手册，不用到处问人。

【怎么用】在你的项目根目录建一个 AGENTS.md，用大白话写清楚：

  • 项目是干嘛的
  • 怎么安装依赖、怎么跑测试
  • 代码风格约定（比如"函数都要写 docstring"）
  • 常见坑（比如"不要改 config.py，那是自动生成的"）

【实用例子】你写了一个 Python 工具库，在 AGENTS.md 里写"测试用 pytest 运行，新增功能必须补测试"。下次 AI 助手帮你改代码时，它会自动遵守这条规矩，改完自己跑测试。
