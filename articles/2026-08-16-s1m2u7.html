你可能已经发现一个奇怪的事：你跟 ChatGPT 或 DeepSeek 聊天，关掉页面再打开，它完全不记得你是谁。这不是它“高冷”，而是模型天生就没有记忆。就像一个人每次见面都失忆，你每次都得重新自我介绍。

那 Agent 是怎么做到“记得你上周说过的话”的？靠的就是短期记忆和长期记忆这套机制。今天学完，你就能说清楚这两者的区别，并且知道长期记忆的一种具体实现方法。这是后面做 Agent 应用的基础——没有记忆的 Agent 就像金鱼，只能做一次性问答。

术语卡片

  • 短期记忆 —— 就是模型“当前这次对话”里能看到的全部内容。相当于你手里拿着的便利贴，上面写着这次聊天的上下文。便利贴有大小限制，写满了就得扔旧的。
  • 长期记忆 —— 存在外部地方（文件、数据库）的信息，需要时再取出来塞进短期记忆里。相当于你的笔记本，可以记很多，用的时候翻出来看。
  • 向量数据库 —— 一种特殊数据库，存的不是表格数据，而是“意思”。它能根据语义找相似内容，而不是靠关键词精确匹配。相当于一个按“意思”分类整理的书架。
  • 嵌入（Embedding） —— 把一段文字变成一串数字（向量），这串数字能代表这句话的“意思”。意思相近的句子，数字也相近。相当于给每句话做一个“指纹”，但指纹的相似度反映的是语义相似度。

原理精讲

1. 模型本身没有记忆：每次对话都是“重新开始”

先做一个思想实验。你拿一张白纸，对着一张照片描述：“这个人穿红衣服。”然后把纸翻过去，再翻回来，问自己：我刚才说了什么？——你不知道，因为你没写下来。

大语言模型就是这样。它每次收到你的提问，都是“第一次”见到你。它没有“上一次我们聊过什么”的概念。你问它“我上次让你帮我写的代码呢？”，它只会一脸茫然。

所以，模型本身只是一个“计算器”，输入一段文字，输出一段文字，完事。记忆这件事，需要靠外部的机制来做。

2. 短期记忆 = 上下文窗口里的内容

那为什么你在同一个对话窗口里连续提问，它好像记得你前面说的？

因为每次你发新消息时，系统会把之前的对话历史也一起发给模型。模型看到的不是“你刚说的这句话”，而是“从对话开始到现在所有的内容”。这些内容就是上下文窗口——也就是短期记忆。

打个比方：你和一个失忆的朋友聊天，你随身带了一个小本子，每次说话前先把之前的对话念给他听。他听完本子上的内容，再回答你当前的问题。本子就是上下文窗口，能写多少字，就是窗口大小（比如 128K tokens）。

问题来了：本子有限，聊太久就写不下了。这时要么丢掉最早的内容（相当于遗忘），要么把内容压缩成摘要（相当于提炼要点）。

3. 长期记忆 = 把信息存起来，需要时再取

短期记忆的问题很明显：一关对话就没了，而且容量有限。解决方法是——把重要的东西写进笔记本。

这个笔记本可以是：

  • 一个普通的文本文件（最简单）
  • 一个 SQL 数据库（结构化）
  • 一个向量数据库（按语义检索）

Agent 的工作流程是这样的：

用户说：“我的项目叫‘蓝鲸’，是一个物联网网关，用的芯片是 ESP32。”

Agent 判断这句话值得记住，于是写入长期记忆库（比如存进文件：“项目名称=蓝鲸，硬件=ESP32”）。

下次用户说：“帮我看看蓝鲸项目的代码。” Agent 先去长期记忆里检索“蓝鲸”，找到相关记录，把“项目=蓝鲸，硬件=ESP32”塞进上下文窗口，然后再回答。

你看，长期记忆的本质是“外部存储 + 检索”。模型本身没记住，但它会“查资料”。

4. 向量数据库为什么适合记忆：按“意思相近”检索

普通数据库有个问题：只能精确匹配。你存了“蓝鲸项目”，用户说“那个网关项目”，普通数据库就查不到——因为关键词对不上。

向量数据库解决了这个问题。它靠嵌入把每段文字变成一串数字（比如 384 个数字组成的向量），然后计算向量之间的距离。意思相近的文字，向量距离就近。

举例：

  • “蓝鲸项目” → 向量 A
  • “那个物联网网关项目” → 向量 B
  • “今天天气不错” → 向量 C

向量 A 和 B 的距离很近（语义相近），A 和 C 的距离很远（无关）。所以当你问“那个网关项目”时，向量数据库能检索出“蓝鲸项目”的记录。

这就是为什么 Agent 的长期记忆大多用向量数据库——因为用户不会每次都说出精确的术语，但意思总能对上。

一句话总结：短期记忆是“现场能看到的”，长期记忆是“存起来需要时再找出来的”，向量数据库让你“按意思找”而不是“按字找”。

动手任务

手机任务（5 分钟）

打开任何一个 AI 聊天 App（DeepSeek、ChatGPT 都行），做一个对比实验：

  1. 新建一个对话，输入：“我叫张三，我喜欢吃重庆火锅。”
  2. 同一对话里继续问：“我叫什么名字？” → 它能答出来（短期记忆在工作）
  3. 关掉这个对话，新建一个对话，问：“我叫什么名字？” → 它答不出来（模型本身没有记忆）
  4. 想一想：如果想让“新对话”也知道你叫张三，你会怎么做？（提示：把这句话放进系统提示词或开场白里）

这个实验能让你直观感受到“短期记忆”和“没有记忆”的区别。

电脑任务（5 分钟，可选）

如果你电脑上有 Python 环境，可以体验一下向量检索的感觉：

pip install chromadb

然后运行以下脚本：

import chromadb

client = chromadb.Client()
collection = client.create_collection("demo")

# 存入两条记忆
collection.add(
    documents=["蓝鲸项目是物联网网关，用ESP32", "今天天气不错"],
    ids=["mem1", "mem2"]
)

# 检索“那个网关项目”
results = collection.query(query_texts=["那个网关项目"], n_results=1)
print(results["documents"])  # 应该返回“蓝鲸项目”那条

不用理解每一行代码，看结果就行：你用“那个网关项目”去搜，返回的是“蓝鲸项目”那条记录——这就是按意思检索。
