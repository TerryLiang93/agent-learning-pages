自己写一个'对话循环'

2026-08-22 · 环境准备 · 预计 30 分钟

今日要点

今天咱们干一件很有成就感的事：亲手写一个能跟你连续聊天的程序。你以为的多轮对话很神秘，其实本质特简单——把之前聊过的话全部打包，再次发给模型。就像你跟朋友聊天，朋友得记得你们刚才说了啥，才能接上话。我们会写一个命令行小工具，跑起来之后你就彻底明白大模型是怎么"记住"上下文的了。

术语卡片

  • 消息列表 —— 就是你和 AI 之间所有对话记录的清单，每一条都标着是谁说的（你是"user"，AI是"assistant"）以及说了啥。程序每次调用模型时，把整个清单一次性发过去。
  • 多轮对话 —— 就是连续聊好几轮，每轮都基于之前聊过的内容继续。对应的是"单轮对话"（每次都是新开始，AI不记得你刚才说过啥）。
  • 历史消息 —— 就是之前几轮你和 AI 说过的所有话。多轮对话的核心就是把这些历史消息一起发给模型，让它"看起来"有记忆。

原理精讲

先想一个问题：大模型有记忆吗？

答案是：没有。大模型本身就像一个金鱼，你每次问它问题，它都当你是第一次见面。它唯一的"记忆"方式，就是你把之前聊过的话写在问题里一起送过去。

打个比方：你去窗口办事，第一次问"我要办居住证"，工作人员给你列了材料清单。你回去准备材料，第二次来直接问"材料齐了，下一步呢？"——如果工作人员不记得你第一次问了啥，就不知道你说的"材料"是啥。所以你得把第一次的对话也带过去："我上次问过办居住证，你让我准备材料，现在我材料齐了，下一步呢？"——这就是多轮对话的本质：把历史消息一起发给模型。

具体到代码层面，调用大模型 API 时，你发送的请求里有一个 messages 字段，它是一个数组（列表），结构长这样：

[
  {"role": "user", "content": "你好，我想学编程"},
  {"role": "assistant", "content": "太好了！你想学什么语言？"},
  {"role": "user", "content": "我想学 Python"}
]

第一轮：你发了第一条消息。第二轮：你发了两条（历史+新问题）。第三轮：你发三条……对话越长，你要发的消息越多，花的钱也越多，AI 的反应也可能变慢。这就是后面要观察的点。

动手任务

手机任务（5分钟）：

打开任意一个 AI 聊天 App（比如 ChatGPT、文心一言、豆包），连续问它几个关联问题，比如：

  1. "给我推荐三道家常菜"
  2. "第一道菜的步骤是什么？"
  3. "如果我想换成素菜，怎么改？"

注意观察：第三个问题它知道"第一道菜"是指你之前问的那道——这就是多轮对话。然后你新开一个对话窗口，直接问"如果我想换成素菜，怎么改？"——看它会不会懵。这就是有历史和无历史的区别。

电脑任务（10分钟）：

写一个最简单的 Python 命令行聊天程序。前提：你已经有 OpenAI 或 DeepSeek 等 API Key（没有的话先去注册一个，DeepSeek 便宜）。

# chat.py
from openai import OpenAI

client = OpenAI(api_key="你的API密钥", base_url="https://api.deepseek.com")

messages = []  # 历史消息列表，初始为空

print("开始聊天吧！（输入 quit 退出）")
while True:
    user_input = input("你：")
    if user_input == "quit":
        break
    
    # 把用户新说的话加入消息列表
    messages.append({"role": "user", "content": user_input})
    
    # 把整个消息列表发给模型
    response = client.chat.completions.create(
        model="deepseek-chat",
        messages=messages
    )
    
    # 取出 AI 的回复，加入消息列表
    reply = response.choices[0].message.content
    print(f"AI：{reply}")
    messages.append({"role": "assistant", "content": reply})

运行方式：pip install openai 然后 python chat.py。

运行后连续聊几句，比如：

  • 你：我叫张三
  • AI：你好张三！
  • 你：我叫什么名字？

如果 AI 回答"张三"，说明多轮对话生效了。然后你观察：聊了 20 轮之后，每次请求是不是越来越慢、花费越来越多？
