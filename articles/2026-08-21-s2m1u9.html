术语卡片

API —— 可以理解成"饭店的菜单+传菜窗口"。你不需要进厨房知道厨师怎么炒菜，你只要按菜单（API 文档）点菜（发请求），服务员（API）就会把菜端给你（返回结果）。在程序里，API 就是别人写好的一套接口，你按规矩调用，就能拿到对方的功能。

API Key —— 相当于"饭店的会员卡"。你点菜（调用 API）的时候必须出示这张卡，证明你是付过钱的客人。没有它，饭店不给你上菜。大模型公司靠这个识别你是谁、扣你多少钱。

SDK —— "别人帮你准备好的工具箱"。比如你要做木工，不用自己磨锤子、锯子，直接买一套现成工具箱。SDK 就是官方帮你封装好的代码库，里面已经写好了怎么调用 API 的细节，你只需要调几个函数就行。

HTTP —— 互联网上"传话的规矩"。就像写信有信封格式、邮局有投递规则一样，程序之间传递数据也要遵守一套格式。你发请求、收响应，都是走 HTTP 这个规矩。你不需要精通它，但要知道它是底层传输的"邮递系统"。

原理精讲

一、整条链路长什么样

咱们把"用 Python 调用大模型"这件事拆开看：

你的 Python 程序
    ↓ 发送请求（带着你的问题 + 你的 API Key）
    ↓ 走 HTTP 协议，经过互联网
大模型服务器（比如 OpenAI、DeepSeek、通义千问）
    ↓ 模型思考，生成回复
    ↓ 走 HTTP 协议，返回结果
你的 Python 程序 ← 拿到回复，打印出来

这个过程跟你在浏览器里问 ChatGPT 完全一样，只不过浏览器换成了你的代码。

二、为什么要用 API Key

你可能会想：我直接调大模型的接口，它怎么知道我是谁？

这就是 API Key 的作用。你在大模型平台注册账号，充值，然后平台给你一串很长的字符——这就是你的 API Key。你每次请求都带上它，平台就知道"哦，是这位用户在调用，扣他的费"。

关键点：API Key 就是你的钱袋子密码，绝对不能泄露。 就像银行卡密码一样，谁拿到谁就能花你的钱。所以咱们要把它放在环境变量里，而不是直接写在代码里。

三、环境变量是什么

【术语】环境变量 —— 就是操作系统里的一些"全局参数"，任何程序运行时都能去读取。比如你的 Windows 系统里有个 PATH 变量，告诉电脑"去哪里找可执行文件"。

咱们把 API Key 存在环境变量里，代码运行时去读它。好处是：

  1. 代码里不出现明文密码，即使代码被人看到，也拿不到你的 Key
  2. 换 Key 的时候不用改代码，改环境变量就行

四、用 SDK 还是直接发 HTTP 请求

两种方式都能调 API，但咱们用 SDK。原因很简单：SDK 帮咱们处理了 80% 的脏活累活——比如拼接 HTTP 请求、处理超时、解析返回格式。咱们只需要写几行代码，就能完成调用。

就好比你要发快递，你可以自己去邮局排队填单子（直接写 HTTP 请求），也可以找快递员上门取件（用 SDK）。后者省事得多。

动手任务

第一步：安装 Python（手机上看步骤，电脑上操作）

如果你已经装过 Python，跳过这一步。没装的话：

  1. 打开浏览器，访问 https://www.python.org/downloads/
  2. 点击黄色的 "Download Python 3.x.x" 按钮
  3. 下载完成后，双击安装包
  4. 重要：安装界面第一页，勾选最下方的 "Add Python to PATH"（这会把 Python 加入环境变量，否则后面命令找不到）
  5. 点击 "Install Now"，等它装完

验证是否装好：按 Win + R，输入 cmd，回车。在弹出的黑色窗口里输入：

python --version

如果显示 Python 3.x.x，说明装好了。

第二步：安装 SDK（电脑任务）

咱们用 OpenAI 兼容的接口来演示。今天用 DeepSeek 的 API 来练习（国内注册方便，价格便宜）。

  1. 打开命令行（Win + R → cmd）
  2. 安装 OpenAI SDK（DeepSeek 兼容这个 SDK）：
pip install openai

看到 Successfully installed openai-... 就说明装好了。

第三步：获取 API Key

  1. 打开 https://platform.deepseek.com/ ，注册账号
  2. 进入"API Keys"页面，点"创建 API Key"
  3. 复制生成的那串字符（注意：只显示一次，关掉就看不到了）

第四步：把 API Key 存到环境变量

在命令行里执行（把 sk-xxxx 换成你自己的 Key）：

setx DEEPSEEK_API_KEY "sk-xxxx"

然后关掉命令行窗口，重新打开一个新的命令行窗口（这一步必须做，否则读不到新设置的环境变量）。

第五步：写代码调 API（电脑任务）

新建一个文件，命名为 test_ai.py，用记事本打开，粘贴以下内容：

import os
from openai import OpenAI

# 从环境变量读取 API Key
api_key = os.environ.get("DEEPSEEK_API_KEY")

# 创建客户端（相当于拿到饭店的会员卡）
client = OpenAI(api_key=api_key, base_url="https://api.deepseek.com")

# 发请求：问模型一个问题
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "你好，请用一句话介绍你自己"}
    ]
)

# 打印模型的回复
print(response.choices[0].message.content)

保存文件后，在命令行里运行：

python test_ai.py

如果看到模型回复了一句话（比如"我是 DeepSeek，一个 AI 助手..."），恭喜你，你已经跑通了第一次 API 调用。

第六步：理解代码在干嘛

逐行看：

  • import os —— 引入操作系统的工具，用来读环境变量
  • os.environ.get("DEEPSEEK_API_KEY") —— 从环境变量里拿你的 Key
  • OpenAI(api_key=..., base_url=...) —— 创建一个"客户端"对象，告诉它"我是谁 + 去哪找服务"
  • client.chat.completions.create(...) —— 这是发请求的动作。参数里 model 指定用哪个模型，messages 是你说的话
  • response —— 这是响应，模型返回给你的所有内容
  • response.choices[0].message.content —— 从响应里把模型说的那句话提取出来
