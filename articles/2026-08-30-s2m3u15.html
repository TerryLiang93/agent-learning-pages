今日要点

今天是你阶段二的大考——不学新东西，把前面学的串起来，独立搭一个"天气助手"Agent。这个助手能听懂你问天气、自己去调天气 API 拿数据、再根据温度给你穿衣建议。关键是：遇到报错或者 API 返回异常时，它能自己发现问题、换个方式再试，而不是直接摆烂。综合实践就是把零散知识点拧成一股绳的过程，就像考驾照路考——不是考你踩油门多熟练，而是考你能不能独立开完整段路。

术语卡片

  • 综合实践 —— 把之前分开学的每个小技能（调 API、写循环、处理报错）合在一起，独立完成一个完整的小项目。就像学做菜，前面学切菜、学调味、学火候，今天要自己独立做出一盘完整的菜。
  • API 返回异常 —— 天气服务那边返回的数据不是我们期望的样子，比如字段缺失、格式不对、或者直接报错。就像你打电话问朋友天气，朋友没接电话，或者接了但说"我不知道"。
  • 自我修正 —— Agent 发现第一次尝试失败了，能自己分析原因、换个方法再试一次，而不是直接放弃或给出错误答案。就像你发消息没发出去，会自动检查是没网还是号码错了，然后重试。

原理精讲

天气助手本质上就是一个"听问题 → 想怎么做 → 动手做 → 看结果 → 不行就换个法子"的循环。

想象你让一个实习生去查今天天气并告诉你穿什么。他的工作流程是：

  1. 听懂需求：你问"北京今天穿啥"，他明白要查北京天气。
  2. 选工具：他知道自己有个天气查询工具，输入城市名就能拿到温度、天气状况。
  3. 调用工具：他把"北京"传给工具，工具返回一堆数据——温度 32°C、晴天、湿度 60%。
  4. 加工回答：他根据 32°C 判断"热，穿短袖短裤，注意防晒"。
  5. 异常处理：如果工具报错"城市不存在"或者返回空数据，他得自己判断——是城市名打错了？还是网络问题？然后换个写法重试，或者告诉用户"这个城市我查不到"。

你之前已经分别学过：怎么定义工具（函数）、怎么让模型决定调用哪个工具（function calling）、怎么写循环让 Agent 多次调用工具。今天就是把它们组装成完整的循环，并且加上"异常处理"这一环——这是之前没系统练过的。

核心就一句话：Agent = 循环 + 工具 + 异常处理。没有异常处理，你的 Agent 就像没有安全气囊的车，平时能开，一撞就废。

电脑任务（10 分钟）：搭天气助手

准备：用你之前搭过的 Agent 框架（LangChain 或直接调 OpenAI API 都行），需要一个免费的天气 API。推荐用 wttr.in，不需要 API key，直接请求 https://wttr.in/北京?format=j1 就能拿到 JSON 格式天气数据。

步骤：

  1. 定义工具函数 get_weather(city: str) -> dict：调用 wttr.in，把返回的 JSON 解析成 {"温度": "32", "天气": "晴", "湿度": "60"} 这样的字典。如果请求失败或返回空，不要直接返回错误，而是返回 {"error": "查询失败"}。
  2. 写主循环：接收用户输入 → 让 LLM 决定是否调用 get_weather → 如果有工具调用，执行并把结果返回给 LLM → LLM 生成最终穿衣建议。
  3. 加异常处理：如果 get_weather 返回了 error 字段，把这个错误信息喂回给 LLM，让它决定怎么办——比如换个城市名格式重试一次，或者直接告诉用户"这个城市暂时查不到"。
  4. 测试这三个场景：
  • 正常：输入"北京今天穿什么？" → 应该返回温度 + 穿衣建议
  • 边界：输入"火星今天穿什么？" → 应该给出合理回应（查不到 / 建议穿宇航服，都算对）
  • 异常：故意把城市名写成空字符串 → Agent 应该能自己发现问题并修正

记录：把你在测试中遇到的问题和怎么解决的写下来，这就是你今天的"踩坑笔记"。

AI 工具箱

主题：为什么"别把 AI Agent 当员工"是给开发者最重要的提醒

【这是什么】HBR 最近发了一篇研究，标题就一句话：别把 AI Agent 当员工对待。这不是哲学讨论，是工程建议。

【为什么值得看】我们做 Agent 的时候，特别容易犯一个错——觉得它"应该像人一样能随机应变"。但实际上，Agent 没有常识、没有责任感、不会"尽力而为"。你如果按照管理员工的方式去设计 Agent（给个模糊目标让它自己发挥），结果大概率是灾难。

【核心要点】设计 Agent 时，把每个步骤都拆到最细、每步都给明确指令和兜底方案。就像你刚才搭天气助手——你不能说"你去帮我查天气吧"，而是要说"调用这个函数，传这个参数，如果返回 error 就重试一次，再失败就告诉用户查不到"。Agent 不需要你像对员工那样信任它，它需要你像对机器那样精确地控制它。
