手写'想→做→看'循环

2026-08-24 · 第一个 Agent · 预计 30 分钟

今日要点

今天我们要亲手写出 Agent 最核心的"大脑回路"：想→做→看→再想，这个循环就是所有 AI 助手干活的基本模式。你还会学会怎么让它"停下来"——不然它会一直想下去，就像一个人反复纠结穿什么永远不出门。学完今天，你就能写出一个真正能自主完成小任务的 Agent 了。

术语卡片

  • ReAct 循环 —— "Reason + Act"（推理+行动）的缩写。就是让 AI 先想一步（Reason），然后做一个动作（Act），看看结果（Observe），再接着想下一步。像人做菜：看菜谱→切菜→看看切得咋样→再决定下一步。
  • while 循环 —— 编程里的"只要条件成立就一直做"的重复结构。比如"只要锅里的水没开，就一直等"。
  • 终止条件 —— 让循环停下来的判断标准。就像"水开了就关火"，没有这个，程序会永远跑下去。

原理精讲

想象你是一个"智能体"（Agent），任务是决定今天穿什么出门。你的思考过程是这样的：

  1. 想：今天冷不冷？我得知道天气。
  2. 做：掏出手机查天气。
  3. 看：看到"25度，晴"。
  4. 再想：25度适合穿短袖。
  5. 做：穿短袖。
  6. 看：穿好了。
  7. 想：任务完成，出门。

这个"想→做→看→再想"的循环，就是 Agent 的核心。在代码里，我们用 while 循环 来实现它：

while 没完成:
    调用大模型 → 让它"想"下一步做什么
    执行它说的动作（比如查天气）
    把结果"看"到（喂回给大模型）

但有个关键问题：怎么知道"没完成"？ 这就是终止条件。有两种典型的终止方式：

  • 任务完成：大模型自己说"我已经知道答案了，任务完成"。
  • 达到最大步数：比如最多循环 5 次，不管完没完成都停——防止 AI 陷入死循环。

打个比方：你让一个实习生去查资料写报告。终止条件就是——他说"写完了"（任务完成），或者你限他 1 小时内必须交（最大步数）。两者缺一不可。

动手任务

手机任务（5 分钟）：不用写代码，用你手机上的任意 AI 助手（比如 ChatGPT、文心一言），让它"查一下明天北京的天气，然后告诉我该穿什么"。观察它的过程——你会发现它先调用工具（查天气），看到结果后，再给你穿衣建议。这就是一个手动版的"想→做→看"循环。体会一下：如果它没查天气直接回答，会发生什么？（会瞎编）

电脑任务（10 分钟）：写一个最简单的 Agent 循环代码。用 Python，不需要任何第三方库，模拟整个过程。

import time

# 模拟"大模型思考"函数
def think(question, context):
    """假装是大模型，根据问题和已有信息决定下一步"""
    if "天气" in question and "温度" not in context:
        return "需要查天气", "查天气"
    elif "温度" in context:
        return "根据温度给建议", "给建议"
    else:
        return "任务完成", "结束"

# 模拟"执行工具"
def execute(action):
    if action == "查天气":
        return "北京明天 25 度，晴"   # 假装这是天气 API 返回的
    elif action == "给建议":
        return "25 度适合穿短袖"
    return ""

# 模拟"观察结果"
def observe(result):
    return result

# ===== Agent 主循环 =====
question = "明天北京穿什么？"
context = ""          # 记录已经知道的信息
max_steps = 5         # 终止条件1：最大步数
step = 0

while True:  # while 循环开始
    step += 1
    print(f"--- 第 {step} 步 ---")
    
    # 1. 想：让模型决定下一步
    reason, action = think(question, context)
    print(f"想：{reason}")
    
    # 2. 终止条件2：模型说任务完成
    if action == "结束":
        print("终止：任务完成")
        break
    
    # 3. 做：执行动作
    result = execute(action)
    print(f"做：执行『{action}』，得到：{result}")
    
    # 4. 看：把结果加入上下文
    context += result + "；"
    
    # 5. 终止条件1：超过最大步数
    if step >= max_steps:
        print("终止：达到最大步数")
        break

print(f"\n最终结论：{context}")

运行后你会看到输出，这就是一个完整的 Agent 循环。试着改一下 max_steps = 2，看看会怎样？再试着把 think 函数里的判断改一改，比如让它永远不说"结束"，看看最大步数怎么兜底。
